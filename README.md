# GMatch

ქართული React/Vite საიტი ჰოსტინგზე ასატვირთად.

## გაშვება ლოკალურად

```bash
npm install
npm run dev
```

## Vercel-ზე ატვირთვა

1. ატვირთე ეს ფოლდერი GitHub-ზე.
2. შედი Vercel-ზე.
3. Import Project.
4. აირჩიე GitHub repository.
5. Deploy.

## დომენის მიბმა

Vercel > Project > Settings > Domains > Add Domain.
შემდეგ დომენის DNS-ში ჩაწერე Vercel-ის მიერ მოცემული records.
